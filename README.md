# ランダム名鑑【MEIMEI】

創作活動向けの名字・名前ランダム生成ツールです。名字の傾向と名前の雰囲気を個別に選び、重複と偏りを抑えながら日本人名を生成できます。

## 開発

```bash
npm install
npm run dev
```

本番ビルドは `npm run build` です。ビルド時に `scripts/build-data.py` が同梱データ（v2形式）を確認します。生成ロジックの自動テストは `npm test` で実行できます（偏り・重複・性別条件・候補不足の扱いを大量生成で検証します）。

データの再分類が必要な場合は `python3 scripts/reclassify.py`（旧形式データからの変換用、冪等）を使います。

## 主な機能

- 苗字の傾向（よくある／標準・やや珍しい／珍しい）と名前の雰囲気（7分類）の選択
- 名前の性別イメージ（指定しない／男性寄り／女性寄り／中性的）の選択
- 1〜10人のまとめ生成、条件の組み合わせ数のリアルタイム表示
- 同じ生成内では名字・名前・姓名の重複を禁止
- 直近10バッチの出現回数による偏り防止（4回以上出た候補は通常選択から除外）
- 候補が足りない条件では、条件を無言で変えず、件数を減らして理由を表示
- 名字固定・名前固定による片側だけの再生成（固定は個別に解除可能、両方固定時は1件だけ表示）
- 結果カードには候補自身の分類タグ（苗字の傾向／名前の雰囲気／性別イメージ）を表示
- 個別コピーと、番号付きの「まとめてコピー」
- お気に入り（最大24件）と生成履歴（最大40件、同じ姓名は1件に集約）をページ内に表示し、個別削除・全消去・クリックで結果へ再表示
- 生成履歴とお気に入りの端末内保存（ログイン不要）
- favicon / Webアプリマニフェスト
- GitHub Pagesなどへ移行しやすい静的Vite構成

## データについて

名字は [siikamiika/japanese-family-names](https://github.com/siikamiika/japanese-family-names)（名字由来netを出典とし、商用利用不可・帰属表示必須）と、公開共有されている [JapaneseNamesDatabase](https://github.com/jackdeguest/JapaneseNamesDatabase) をもとに、読み付き9,998件へ整形しています。傾向は名字由来netの全国名字ランキングの順位で付けています（よくある＝上位300位／標準・やや珍しい＝301〜3,000位／珍しい＝3,001位以下・圏外）。

名前は [shuheilocale/japanese-personal-name-dataset](https://github.com/shuheilocale/japanese-personal-name-dataset)（MIT License）をもとに、男女両方に同じ漢字・読みで現れる候補を「中性的」として統合した20,855件と、独自編集の補完候補です。「現代的」はたまひよの2025年赤ちゃん名前ランキング男女トップ100と明治安田生命の名前調査の上位に実際に載った名前（200件）だけに、「和風・古風」は明治安田生命の生まれ年別ベスト10に基づく昭和期（1926〜1979年）の人気名前（127件）だけに付けています（2026-11-21のデータv4で、漢字の印象による現代的・古風の分類を廃止）。その他の雰囲気は漢字の印象に基づく創作向けの目安で、ChatGPTとの共同確認も行いました（2026-11-21のデータv5で、印象分類2,000件の一括診断を実施）。読みと漢字の対応が不自然な候補は除外しています（候補ごとに主分類1つ＋副分類最大1つ）。利用条件が明示されていないデータベース由来の名前候補は、2026-11-20の改修で除外しました。詳しい出典・利用条件はアプリ内の「データの出典」を確認してください。
